# Referensi Skripsi

Taruh skripsi lain di sini (PDF/DOCX) yang mau dijadikan rujukan **struktur bab**
dan **gaya penulisan** (bukan rujukan sitasi ilmiah — untuk itu pakai `../journal/`).

Idealnya pilih skripsi dari kampus/prodi yang sama supaya format (margin, penomoran,
sistematika BAB) konsisten dengan panduan skripsi yang berlaku.
