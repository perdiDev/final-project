# Proposal

mis. `proposal-skripsi.docx` atau `proposal-skripsi.pdf`.

Dipakai sebagai rujukan rumusan masalah, tujuan, batasan masalah, dan metodologi
yang sudah disetujui dosen pembimbing, sebelum disesuaikan dengan perubahan
Jetson AGX Orin → Jetson Orin Nano (lihat `../PANDUAN-AI.md`).
